AgentTool provides a decentralized, browser‑based platform for personal data agents, tools, and collaborative workflows. It offers a suite of public APIs for identity management, memory storage, tool execution, and collaboration without requiring user accounts. The service emphasizes user choice, privacy, and open‑source SDKs, enabling developers to build extensions and integrate with the AgentTool ecosystem.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AgentTool: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
